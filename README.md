# وب‌پروکسی شخصی — نسخه Node.js (۳)

مرورگر پروکسی فارسی با تب‌ها، پشتیبانی یوتیوب (HLS)، سوییچ بین چند سرور و **تغییر IP خروجی**.

این ریپو منبع استقرار خودکار است (Railway / Render).

## قابلیت‌ها

- رابط «مرورگر» کامل: تب‌ها، تاریخچه، نشانک‌ها، بزرگ‌نمایی، جستجو در صفحه
- بازنویسی کامل لینک‌ها/تصاویر/فرم‌ها + پچ fetch/XHR سمت کلاینت
- پخش یوتیوب با انتخاب کیفیت (صفحه‌ی اختصاصی + پخش‌کننده HLS)
- **تغییر IP خروجی** (نسخه ۳): مستقیم / چرخش خودکار بین پروکسی‌های رایگان سالم / پروکسی شخصی — از منوی ⋮ ← «تغییر IP خروجی»
- موتور سرعت: اتصال‌های زنده (keep-alive)، پاسخ استریمی فوری، کش درون‌حافظه‌ای
- بدون رمز (یا با رمز، اگر متغیر `PROXY_PASSWORD` را تنظیم کنی)

## استقرار

### Render (ساده‌ترین راه — رایگان)

[![Deploy to Render](https://render.com/images/deploy-button.svg)](https://render.com/deploy?repo=https://github.com/freerouter11/web-proxy-deploy)

### Railway

```bash
RAILWAY_TOKEN=rlwy_wksp_... node railway-deploy.mjs
```

### هر جا که Node.js ≥ ۱۸ باشد

```bash
npm install
node server.js
```

## متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
| --- | --- | --- |
| `PORT` | `3000` | پورت گوش‌دادن (پلتفرم‌ها خودشان تنظیم می‌کنند) |
| `PROXY_PASSWORD` | خالی | اگر تنظیم شود، ورود با رمز فعال می‌شود |
| `PROXY_LIST_URL` | فهرست پروکسی رایگان monosans | منبع استخر پروکسی برای چرخش IP |
| `POOL_SIZE` | `20` | تعداد پروکسی سالم نگه‌داشته‌شده در استخر |
