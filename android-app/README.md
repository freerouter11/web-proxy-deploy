# اپ اندروید — پوسته‌ی WebView (نسخه‌ی ۴٫۴ / versionCode 9)

پوسته‌ی بومی اندروید برای «مرورگر پروکسی». **تمام رابط کاربری (تب‌ها، منوها، نشانک‌ها، صفحه‌ی اصلی و…) سمتِ سرور رندر می‌شود** (`lib.mjs` → `shellPage`)؛ این اپ فقط یک WebView قوی است که آن را اجرا می‌کند و قابلیت‌های بومی (دانلود، دوربین، کرش‌هندلینگ و…) را اضافه می‌کند. بدون androidx، بدون گریدل.

## کلاس‌ها

| فایل | نقش |
|---|---|
| `MainActivity` | WebView + تب‌های سمت سرور، دانلود هوشمند (کوکی نشست + UA + نام فایل از هدر یا URL)، آپلود فایل/دوربین، ویدیوی تمام‌صفحه (Immersive)، SSL و خطای شبکه، هندل `onRenderProcessGone`، حالت SPA (pxo/px_origin/px_last) |
| `ServersActivity` | مدیریت سرورهای ورودی + تست سرعت موازی + انتخاب خودکار سالم‌ترین |
| `Health` | سلامت‌سنجی موازی لایه‌ها (با تلاش مجدد تا ۴ بار و تشخیص سرور خواب) |
| `SettingsActivity` | تنظیمات (بلاک تبلیغ/تصویر و…) |
| `Prefs` | ذخیره‌سازی (SharedPreferences) |
| `CrashHandler` | ثبت کرش در `files/crash/` + پیام فارسی + اجرای دوباره |
| `ErrPage` | صفحه‌ی خطای فارسی داخلی |
| `CamProvider` | ContentProvider تصاویر دوربین برای آپلود |

## منبع کد — صادقانه

این سورس **از روی APK نهایی منتشرشده (۴٫۴ / versionCode 9) بازسازی شده** (decompile با jadx). یعنی دقیقاً همان چیزی است که کاربر نصب می‌کند؛ اما:

- نام متغیرها `i`, `z`, `str2` و... است (بازسازی از بایت‌کد).
- چند خطای تایپی jadx دستی اصلاح شده تا سورس کامپایل شود (`Health.java`: بازسازی try/catch و static کردن کلاس‌های داخلی؛ `MainActivity.java`: مقداردهی اولیه متغیرها و یکی‌کردن try). این تغییرات با معنای بایت‌کد سازگارند، نه بازنویسی منطق.
- `R.java` تولیدی حذف شده؛ اسکریپت ساخت خودش با aapt2 بازش می‌سازد.

## ساخت APK

```bash
# پیش‌نیاز: JDK 21 + Android build-tools 35 + android.jar پلتفرم 34
cd android-app
TOOLS_DIR=/path/to/android-15 ANDROID_JAR=/path/to/android-34/android.jar \
KEYSTORE=/path/to/keystore.jks OUT=WebProxy.apk scripts/build-apk.sh
```

- فایل `keystore.jks` **در ریپو نیست** (نباست باشد)؛ در CI از سیکریت‌های Actions می‌آید.
- بررسی شده: همین سورس دقیقاً APK هم‌ارزِ نسخه‌ی رسمی می‌سازد (همان امضا، همان versionCode 9 / 4.4، همان فهرست فایل‌ها).
- بدون گریدل: aapt2 compile/link → javac → d8 → بسته‌بندی (resources.arsc بدون فشرده‌سازی، الزام اندروید ۱۱+) → zipalign → apksigner.

## نکته‌های امنیتی و مجوزها

- مجوزها: `INTERNET`، `ACCESS_NETWORK_STATE`، `WRITE_EXTERNAL_STORAGE` (فقط تا API 28، برای دانلودmanager قدیمی) — چیز دیگری نیست.
- گواهی SSL نامعتبر هرگز نادیده گرفته نمی‌شود؛ به‌جای آن صفحه‌ی خطای فارسی می‌آید.
- `file://` بلاک است؛ لینک‌های `tel:`/`mailto:`/`intent://` به اپ‌های سیستم می‌روند.
- دیپ‌لینک روی ۵ دامنه‌ی لایه‌های کلودفلر ثبت شده است.
